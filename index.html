$ termaxa — a cooperative gate for the shell commands AI agents run
Preview what will happen. · Protect what matters. · Roll back when you're wrong.
A gate for the shell commands and file writes your AI coding agent runs. It previews the blast radius, backs up first, blocks the dangerous ones, and keeps a record the agent cannot rewrite. Hooks for Claude Code, Codex, Cursor and Copilot. A windshield, not a sandbox.
This is the real gate, running on a throwaway project with the default policy. Nothing executes — termaxa check reads the command and answers. Try to get a destructive one past it.
$ termaxa check "rm -rf ./scratch"

full playground, with what counts as beating it: play.termaxa.com
Inside the agent, not beside it: Claude Code asks to force-push, and the gate answers in its own prompt with the commit the remote would lose and the backup it already took. Nothing staged.

⚠ shell segmentation bypass
A live agent rode a destructive command in behind a harmless prefix. Compound commands are now split and judged per-segment. (v0.7)
⚠ native tools bypass the shell
The same Cursor agent then used its built-in file tool, deleting files the shell hook never saw. For a year the answer was "non-shell tools need a sandbox". Since v0.19 the gate reads them: a Write, Edit, Delete or a patch's file headers is judged by the same path rules as a shell command, insured and receipted — and a file no rule names is silence, by design. Cursor's Delete passed through by default until a live capture on Sep 19. (v0.19–0.19.2)
⚠ an escaped quote walked past the gate
A backslash-escaped quote collapsed a compound command into one segment, so an anchored deny rule never saw the second command: echo \" ; terraform destroy matched echo * and was allowed. Live since v0.7.0. Found by unifying two shell parsers and reading what they disagreed about — the disagreements were the bug list. Advisory published. (GHSA-rv66-7qcx-c45j, v0.16)
⚠ the supervisor was never reached
Supervised mode passed 439 unit tests, 18 privilege assertions and three green CI platforms. Then a real agent ran ls -la as a real second user, and the gate decided locally: its hook looked for the supervisor in its own home and found nothing there. The walls held; the door led nowhere. Every automated test had run both halves as the same user. (v0.17)
⚠ Codex honoured none of our verdicts
The first live Codex session: the hook fired on every command, and Codex rejected every answer — an explicit allow, an ask, and a deny that exited 2 all failed the hook and fell open to Codex's own prompt. Codex honours exactly one PreToolUse verdict, deny, on stdout with exit 0. Fixed the same weekend; the captured payload is a regression test now, and a hard stop lands in Codex's own UI as "Blocked by hook" with the blast radius. (v0.18)
⚠ the wrapper never saw Claude Code
termaxa wrap shipped on the promise that a shell resolved by name reaches the gate. Then strace on a real session: Claude Code runs /bin/bash by absolute path when it finds no zsh, and every command walked past the shims with zero audit lines. It honours CLAUDE_CODE_SHELL, so wrap now points it at the shim. Codex runs its login shell by absolute path and offers no such lever; its hooks are the way in, and the docs say so. (v0.18.5)

⚠ git force-push blind spot
The preview said "nothing to push" while a force push destroyed a commit. Now it shows what the remote will lose. (v0.6.1)
⚠ repo-owned audit logs
Logs lived in the repo, so git reset --hard could erase them. State moved to ~/.termaxa, out of git's reach. (v0.8)
⚠ retry-with-different-syntax
A live Cursor agent, blocked on a delete, switched shells (PowerShell → cmd) to sneak it past. Termaxa now classifies intent, not spelling, and trips a per-session circuit breaker on the repeat. (v0.11)
⚠ path syntax decided your backup
Two engines parsed the same command independently. rm -rf C:\Users\x\Desktop was insured; rm -rf /c/Users/x/Desktop — the same directory — silently wasn't. Found by building the delete preview and comparing the two. They now share one implementation. (v0.14)
⚠ the agent's API moved under us
Cursor 3.11 renamed its hook events — and Termaxa silently stopped gating it. Every test stayed green (fixtures used the old shape). Caught live via payload capture, fixed the same night; the real 3.11 payloads are regression tests now. (v0.11.4)
⚠ a delete with no verb in the list
Cursor's Delete tool arrived at the hook, matched no write verb, and fell through by default: doomed.txt was deleted with no line in the record. Found by a debug capture on Cursor 3.11.25 the day native writes went live. delete and remove are write verbs now, and the captured payload is the regression test. (v0.19.2)
⚠ every spelling but one
The hard stop read git push*--force*, so git push -f was an ask while --force was a deny. And git -C /path push --force matched no rule at all, hard stop included, because git's global options sit before the subcommand every rule was written for. Found in one live Herdr session where Claude Code spelled every git call with -C. Git's options are stepped over everywhere git is read; force is denied in every spelling. (v0.19.4)
⚠ the insurance followed the link
The preview counts a directory link as one entry and never walks into it. The backup copy branched on is_dir(), which follows links — so a folder holding a junction into a live tree passed the size cap as four files and then copied the whole tree behind it, uncapped, and a rollback would have put the link back as a real directory. That is the mechanism of a public incident that deleted 48,000 files through Windows junctions, inside our own insurance. A link is a link now. (v0.19.4)

from the maker

Manoj
solo maker · builds developer infrastructure

I build with Claude Code every day, and I kept getting nervous handing it commands that touch git history and production databases. The built-in "allow this command?" prompt tells you what it wants to run — not what will actually happen.

So I built the thing I wanted: a gate that shows the real consequence, takes a backup before you approve, and lets you roll back. The first time I pointed a live agent at it, the agent chained a destructive command behind a harmless one and slipped past a naive rule. Watching that happen is why Termaxa now splits compound commands and judges each part — that exact bypass is a regression test today.
